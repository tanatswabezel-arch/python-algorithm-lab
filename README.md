# Dictionary.
A dictionary is a Python data structure that stores data using keys and values , so you can  quickly find information using a name instead of a position .

| Feature          | Linear Search    | Binary Search      |
| ---------------- | ---------------- | ------------------ |
| Data Requirement | Any list         | Must be sorted     |
| Speed            | Slow             | Fast               |
| Method           | Check one by one | Divide and conquer |
| Time Complexity  | O(n)             | O(log n)           |
